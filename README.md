# Lean Chats

Keep project conversations manageable with summaries and short handovers.

## Install

Clone this repository into your agent's skills directory, keeping `SKILL.md` and its supporting files together. For Codex:

```sh
git clone https://github.com/felipepetersmann22-star/lean-chats-skill.git ~/.codex/skills/lean-chats
```

Restart or refresh skill discovery if needed. Other agents may use a different skills directory.

## Use

Use when a conversation becomes long, a project finishes, or work resumes from an earlier conversation. The included handover template is in `assets/handover-note.md`.
